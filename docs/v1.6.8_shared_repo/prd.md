# PRD — 팀 공유 레지스트리 + 이종 런타임 교환 (v1.6.8 shared_repo)

> 대상 릴리스 라벨: **v1.6.8**(팩토리 버전 라인·현 1.6.3). 하네스웹 신규 화면 `#/registry` + 레지스트리 규약.
> 근거: 세션 설계 논의(팀 대상·전원 개발자·git 레지스트리·이종 교환·댓글 계층·보안 게이트) + 실제 자산(F12 런타임 레지스트리·F13/F16/F17 읽기·동기·설치·F7 편집기/diff·#/eval 4축·plugin marketplace 패턴).
> 설계 상세: [`design.md`](./design.md).

---

## 1. 문제 · 목표

### 1-1. 문제
개인이 만든 스킬·에이전트가 **로컬에만 갇혀** 팀원 간 공유·재사용·개선이 안 된다. CLI/plugin marketplace 는 "패키지 배포"엔 되나, 팀 내부의 **비공식 상호 공유(내가 만든 걸 동료가 골라 받고, 의견 남기고, 서로 개선)** 와 **이종 런타임 교환**(클로드 사용자가 올린 스킬을 코덱스 사용자가 설치)엔 맞지 않는다.

### 1-2. 목표
1. **원격 저장·버전·롤백·접근제어** — 팀 공유 저장소(사설 git repo)에 스킬·에이전트를 두고 관리.
2. **평가** — 공유 아티팩트마다 자동 품질 등급(#/eval 4축 재사용) + 사람 댓글(경험지).
3. **이종 런타임 교환** — 클로드/코덱스/제미나이 사용자가 서로의 아티팩트를 **설치·사용**. 스킬은 즉시(동일 SKILL.md), 에이전트는 번역 계층 + 충실도 보고.
4. **안전한 공유** — 설치 전 사람 검토(diff·요구 권한·등급)·자동 설치 금지·게시 전 시크릿 스캔.

### 1-3. 비목표 (v1.6.8)
- 호스팅 **서버**(auth·멀티테넌트·전송보안·가동률) — git+GitHub 권한으로 대체. 비기술 사용자·실시간 협업은 후속.
- **불특정 공개 배포**(서명·샌드박스) — 대상은 **팀·상호신뢰**. 공개는 별도 설계.
- **완벽한 자동 에이전트 교환** — 런타임 고유 능력은 손실 가능 → "구조 이식 + 충실도 경고"까지만 약속.
- 다중 프로젝트·자동 커밋(push)·blind 자동 적용.

## 2. 사용자 · 시나리오

**대상:** 같은 팀·전원 개발자·git 사용·상호 신뢰(같은 org private repo). 신뢰 모델 = "팀-검토됨".

### 2-1. 핵심 시나리오
- **US1 (게시):** A유저(클로드)가 만든 스킬을 팀 레지스트리에 **PR로 올린다**(직접 push 아님). 자동 첨부 = eval 등급·요구 권한 요약·시크릿 스캔 결과.
- **US2 (발견·설치):** B유저(코덱스)가 레지스트리를 브라우징(목록·등급·소유자·요구 tools·★사람평) → "가져오기" → **검토 관문**(diff + 요구 권한 + 등급 + **이종 충실도 경고**) → 승인 → 자기 런타임 채널에 설치.
- **US3 (이종 교환):** A(클로드)가 올린 **스킬**을 B(코덱스)가 그대로 설치·사용(동일 SKILL.md). A가 올린 **에이전트**(.md)를 B가 설치 시 → md→TOML 번역 + "클로드 전용 tool X 무시됨" 경고.
- **US4 (의견):** C유저가 스킬 스레드에 "대용량서 느림 주의" 댓글 + 추천(★).
- **US5 (동기·drift):** 레지스트리가 갱신되면 pull → F16 drift 감지 → 내 로컬 사본 갱신 여부 선택.

## 3. 범위 (단계) · 리스크 등급

리스크=**중대**(원격 배포·다수 쓰기·실행 지시문 공급망·이종 번역). 각 중대 단계 외부감사 ≥2회 no-high 2연속.

| 단계 | 내용 | 이종 교환 | 등급 | 신규 코드 |
|------|------|-----------|------|-----------|
| **S0** | git 레지스트리 규약 + CI 자동채점(evaluateArtifacts) + 수동 pull/설치 | 스킬만(동일 포맷) | 표준 | ~0(규약·CI) |
| **S1** | `#/registry` 화면 — 브라우징·**검토 관문 import**(F7 diff·F17 설치 재사용)·PR publish | 스킬 + 에이전트(클로드↔제미나이 복사) | 중대 | 얇음(신뢰 레이어) |
| **S2** | 에이전트 **중립 IR + md↔TOML 어댑터 + 충실도 경고** · 시크릿 스캔 게이트 · Discussions 댓글/추천 노출 | 에이전트 전체(↔코덱스) | 중대 | IR·어댑터·스캐너 |
| **S3(후속)** | 서명·출처·사용 카운트·앱내 댓글창 · (필요 시) 서버 | — | — | — |

> **스킬-먼저 원칙:** 스킬은 세 런타임 SKILL.md 동일 → 번역 위험 0 → S0/S1 즉시 가치. 에이전트 번역 리스크는 S2로 격리.

## 4. 수용 기준 (Acceptance Criteria)

> ID 규약 = `AR{n}`(Acceptance-Registry). 각 단계 게이트 = 결과서 + 외부감사 + 커밋 게이트.

### S0 — 레지스트리 규약 + 평가
- **AR1** 레지스트리 repo 표준 구조(`skills/{name}/SKILL.md`·`agents/{name}/…`·`index.json` 카탈로그) 문서화·예시 커밋.
- **AR2** CI(레지스트리 repo)가 PR마다 `evaluateArtifacts` 상당 채점 → 등급/지적을 체크로 게시. **D등급 머지 차단**(옵션).
- **AR3** 스킬 수동 교환 실증: 클로드가 올린 SKILL.md 를 코덱스 채널(`.agents/skills`)에 설치 → 정상 로드(선검증 dogfood).

### S1 — #/registry UI + 검토 관문
- **AR4** 레지스트리 URL 을 config 에 등록(1회)·다중 URL 리스트 허용(marketplace 패턴). 경로/URL 검증·fail-closed.
- **AR5** 브라우징: 목록 = 이름·kind·runtime-origin·소유자·**eval 등급**·요구 tools/model·(있으면)★사람평·댓글수. 읽기전용.
- **AR6** **Import 검토 관문(비협상·R1 재정의):** **본문 전문 강제 검토**(짧으면 전문/길면 스크롤·"검토함" 체크) + **정적 위험 스캔 배지**(본문의 RCE/exfil·네트워크·env/secret 읽기·prompt-injection·런타임 결합) + diff(F7) + **선언 tools/model 은 "비신뢰 참고" 라벨**(안전 경계 아님) + eval 등급 "품질·비안전" 라벨 + 이종 충실도 경고 → 위험 배지 있으면 **명시 확인 전 설치 버튼 비활성** → 사람 승인 후 **IR 재렌더**(저장 렌더물 비신뢰)로 F17 설치. **원격 자동 설치 절대 금지.** *(요구 권한 요약만 신뢰하면 거짓 안전감 — R1 HIGH.)*
- **AR7** Publish = **PR 생성**(직접 push 아님)·게시 전 요구 권한·eval 등급 자동 첨부.
- **AR8** 스킬 이종 설치: 받는 사람 런타임 채널로 폴더 선택 설치(F17)·백업·drift 감지(F16). 클로드↔제미나이 에이전트(동일 md) 복사 설치.
- **AR9** 쓰기경계 회귀 세트(A184 상당) 재사용·전건 PASS(경로탈출·심링크·nlink·Windows 차단). 게이트 기본 off.

### S2 — 에이전트 이종 번역 + 신뢰 + 댓글
- **AR10** 에이전트 **중립 IR** 스키마 정의(`name·description·instructions·tools[]·model_hint·runtime_origin·rules_ref`). 게시 시 추출·저장.
- **AR11** md↔TOML 어댑터(F14/F15 재사용): IR → 대상 런타임 렌더. **왕복 무결성**(canonical=진실·재추출 금지).
- **AR12** **충실도 보고:** 안 옮겨지는 항목(런타임 고유 tool·모델 ID·미지원 키)을 검토 관문에 명시 경고. 손실 0 요구 아님·**정직한 보고** 요구.
- **AR13** **정적 위험/시크릿 스캔 게이트(게시+가져오기 양쪽·R1 확대):** 시크릿(API 키·토큰·절대경로) 외 **본문 RCE/exfil 지시**(`curl|sh`·`eval`·`base64 -d`·네트워크·env/`.ssh`/`.aws`/`.env` 읽기·prompt-injection) 감지. 게시=시크릿 발견 시 차단. 가져오기=위험 발견 시 명시 확인 전 설치 불가. fail-closed·오탐 허용.
- **AR15** **eval 등급 ≠ 안전 UI 강제:** 등급 배지에 "품질·비안전" 상시 병기·위험 스캔 결과와 **분리 표시**. 평가 세탁(악성이 A 받아 신뢰 획득) 인지편향 차단(R1 MED).
- **AR16** **untrusted 캐시 샌드박스:** clone 캐시 읽기(diff·스캔·index·설치 소스) 전 경로에 심링크 거부·크기 상한·경로 allowlist·submodule/LFS off(R1 HIGH).
- **AR17** **IR 무결성:** 설치=IR 재렌더(저장 렌더물 비신뢰)·게시=IR base merge(타 런타임 extras 보존)·재추출 금지(R1 HIGH).
- **AR14** 댓글/추천: 스킬당 GitHub Discussions 스레드 링크·(가능 시)카드에 댓글수/★ 노출. 앱내 게시는 S3.

## 5. 안전 원칙 정합 (재발명 금지)

| 기존 원칙(레포 교리) | 이 기능에서 |
|---|---|
| 사람 diff 승인 = 유일 적용 트리거(F7) | **Import 도 검토 관문 유지** — 원격 자동 설치 금지(AR6) |
| 쓰기경계·경로안전(A184·F17) | 설치=F17 재사용·회귀 세트 재사용(AR9) |
| 리스크 등급 게이트 | 저위험 스킬 우선·에이전트 번역은 S2 격리 |
| 읽기 우선·게이트 기본 off | 레지스트리 mutation(설치·게시)도 게이트·기본 off |
| eval 은 품질이지 안전 아님(#/eval) | **등급≠안전** — 품질 등급 + 별도 사람 검토(권한·시크릿) 병행 |
