## 4. 미해결 / 후속
- **런타임 validator registry**: 현재 Gemini=Claude md validator 재사용(안전·미지 필드 보존). 실 필드 차이 드러나면 후속 분리.
- **Windows route 501**: POSIX CI서 직접 회귀 테스트 없음(win32 전용·writeDefSafe 단위 계약으로 커버).
- **create-gemini**: create route runtime 태그는 아직 claude(편집=M-c·생성-gemini는 후속).
- **심링크-편집 리다이렉트(§4-2)**: 현재 심링크 정의 거부(안전). 신뢰 타깃 리다이렉트는 프로젝트 정의가 심링크인 드문 경우용·후속(현 거부로 무해).
