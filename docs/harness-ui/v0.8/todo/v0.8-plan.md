## 0. 공통 작업규칙 (전 마일스톤 의무 · 하네스 작업규칙 준수)

> 아래는 **모든 마일스톤에 무조건 적용.** 단계별 섹션은 이 규칙을 참조만 하고 중복 서술하지 않는다.

### 0-1. 외부감사 ≥2회 (중대 등급·비협상)
- 각 마일스톤 구현 완료 후 `external-review-loop` 스킬로 **외부감사 실행** — 리뷰어 = **러너 엔진 제외분**(`bash skills/myharness/scripts/check-review-tools.sh {runner}` 끝줄 `REVIEWERS:` 기준). 이 하네스 러너=claude → **codex + agy**. (러너=codex면 claude+agy·러너=gemini면 claude+codex.) 저하 모드: 하나만 있으면 그것만·none이면 내부 QA만+명시.
- **loop-until-dry: 최소 2회 이상 + 양 엔진 no-high 2회 연속 수렴까지 반복**(1회로 종료 금지). 신규 확인 이슈 0건이 K회 연속 or MAX_ROUNDS.
- 판정 = 오케스트레이터 **실코드 대조 전건 판정**(확인/부분/이월/기각·근거). 위임 금지. 확인분만 TDD 수정 → 수정 diff 재리뷰.
- **측정 꼬리(누락 금지):** 루프 종료 → `verdicts.json` → `build-scorecard.sh` → `summary.jsonl`(loop_scorecard). raw audit만 돌리고 측정 꼬리 스킵 금지(v1.5.0 회귀 재발 방지).

### 0-2. working_history 작업결과서 (매 마일스톤·의무·물리 게이트)
> 영속 산출물(결과서)은 `docs/`(커밋 원장)에 남긴다. `_workspace/`(휘발) 방치 시 재실행/cleanup서 소멸 → 감사 이력 0. **프롬프트로 못 막으므로 게이트로 강제.**
- 마일스톤 게이트 PASS 직후 `docs/harness-ui/v0.8/working_history/{M}_{slug}_{YYYYMMDD_HHMMSS}.md` 작성(**덮어쓰기 금지**·기존 M14/M15 관례). 골격 = `skills/myharness/references/templates/working-history-skeleton.md`.
- **필수 내용:** ①작업 요약(완료 항목) ②변경 파일(경로+사유) ③검증 결과(테스트 통과/전체·회귀·RED→GREEN·**해당 A18x 통과 현황**·게이트 수치) ④미해결/후속 ⑤**외부 리뷰 반영**(codex+agy 판정 digest·확인/부분/이월/기각+근거·raw는 `_workspace/reviews/` 링크·본문 복붙 금지) ⑥**`## 다음 단계 참조`**(미해결·핵심 결정과 이유·다음 마일스톤 착수 조건).
- ⚠ **`## 다음 단계 참조` heading 문자열 유지**(RAG 연속성·`check-artifacts.sh` 매칭). `_workspace` 소실돼도 이 결과서만으로 자기완결.

### 0-3. 커밋 순서 게이트 (마일스톤 단위)
리뷰→판정→수정→PASS(typecheck·build·전체 테스트 그린) → `bash skills/myharness/scripts/check-artifacts.sh docs/harness-ui/v0.8 t1`(끝줄 `ARTIFACTS: ok`·missing이면 커밋 차단·생성 하네스면 그 하네스 scripts/ 사본) → **승인 관문(중대: 사용자 승인 대기)** → 단일 커밋. pre-commit hook이 스테이징된 신규 결과서 물리 검증.

### 0-4. TDD (코드 에이전트 실경로)
빌더·수정·QA는 `skills/myharness/references/{dev-rules,tdd-doctrine}.md`(생성 하네스면 그 하네스 references/ 사본) 준수 — RED(결함/계약 재현) 검증 후 GREEN. 계약·스키마·보안 테스트만 외부 교차리뷰 대상.

### 0-4b. 공통 mutation 보안 게이트 (A189·A184 · 전 쓰기 마일스톤 물리 배선 · 비협상)
> 새 쓰기 경로/라우트가 생기는 **모든** 마일스톤(M-c·M-d·M-e·M-f)은 아래를 **게이트 테스트로 PASS**해야 커밋. "심링크 대조" 수준으로 약화 금지.
- **A189(공통 mutation gate):** 새 mutation route 전부 `security.ts` **Host/Origin allowlist·세션 토큰·127.0.0.1 bind·no-CORS·preflight 실패 거부·`definitionEditEnabled`/`factoryMaintenanceEnabled` 게이트** 통과. **각 route에 게이트 우회 시도 거부 테스트**(R8-i CSRF/rebinding).
- **A184(쓰기경계 회귀 세트·공유):** 파일 mutation 있는 마일스톤은 아래 **공용 쓰기경계 회귀 스위트를 재사용·전건 PASS**: per-seg lstat·root realpath containment·**최종 파일 심링크 금지(O_NOFOLLOW)**·**app-level open+fstat (dev,ino) 재검증**·parent-dir race·temp 동일 dir·rename inode 재검증·**nlink>1 거부**·platform matrix(Windows write 차단)·**negative: `.env`/`.git`/projectRoot-inside-untrusted·trusted-root symlink·hardlink·open-after-swap harness**·게이트 default off.
- 이 세트는 **M-c에서 신설·M-d/M-e/M-f는 회귀 재사용**(중복 구현 금지). 각 마일스톤 결과서(0-2)에 A189·A184 통과 현황 수치 기록.

### 0-5. 팀 (harness-ui-dev 하네스)
`spec-planner`(계획 상세)·`server-builder`(`src/server/**`)·`web-builder`(`src/web/**`)·`qa-verifier`(경계면 교차·incremental)·`security-auditor`(쓰기경계·심링크·경로안전). 모델 opus.

### 0-6. 실행 선결 (착수 전 확인·코드레벨 리뷰 반영)
- [ ] **팀 존재:** 위 5 에이전트(`.claude/agents/{spec-planner,server-builder,web-builder,qa-verifier,security-auditor}.md`)가 로컬에 없으면 `harness-ui-dev` 스킬로 **(재)구성 선행**. 부재 시 대체는 generic 에이전트가 역할 수행(정의 파일 명시).
- [ ] **강제 게이트 배선(프롬프트 의존 금지):** `.git/hooks/pre-commit`(결과서 물리 검증) **미설치 확인됨** → **M-a 착수 전 hook 설치 필수**(orchestrator-template hook 절차·리터럴 baked PROJECT=`harness-ui/v0.8`·TIER=`t1`). 설치 불가 시 → **사용자 승인 받은 예외 기록** + 매 커밋 직전 `check-artifacts.sh`(§0-3) 실행 로그를 결과서(0-2)에 첨부(수동 게이트 증적).
- [ ] **스크립트 경로:** `check-artifacts.sh`·`build-scorecard.sh`·`emit-loop-scorecard.sh`는 `skills/myharness/scripts/` 정본 확인(생성 하네스면 그 하네스 `scripts/` 사본). external-review-loop 스킬 정본 = `skills/myharness/references/external-review-loop.md`.
